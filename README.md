# ASTRAEUS

Premium exploration and lifestyle storefront for ASTRAEUS, a concept brand under Carlisle Capital LLC.

Single page site, no build step. Open `index.html` or serve the folder.

- Lightspeed intro page, then the landing page
- Watches, watch storage, field equipment, everyday equipment, apparel, firearms
- Six mission collections with insignia
- Search, filters, sorting, wishlist, cart, checkout, order confirmation, demo account
- Original SVG product art, drifting star field, navy / white / silver / orbital blue palette

Payment is a demo. Firearms copy is written compliance first (21+, FFL transfer only) but needs legal review before any real sales.
